# Примеры для проверки ML-функций

## OCR (распознавание текста)

| Файл | Язык | Содержимое |
| --- | --- | --- |
| `ocr-sample-rus.png` | rus | Ядро сети: 10.0.0.0/24; Коммутатор SW-CORE-01; Порт Gi0/1 -> провайдер |
| `ocr-sample-eng.png` | eng | Lab network acceptance checklist; VLAN 10 users, VLAN 20 voice |

Как проверить:
1. В приложении: Заметки → открыть заметку → «Распознать текст» → загрузить образец → «Вставить в конец».
2. Через API:
   ```bash
   curl -s -X POST http://localhost:3000/api/ocr \
     -H "Authorization: Bearer $TOKEN" \
     -F "image=@samples/ocr-sample-rus.png" -F "lang=rus"
   ```

## Распознавание набросков (редактор схем)

Рукописные образцы не нужны в виде файлов — эталоны каждого обозначения
показываются прямо в редакторе («Показать легенду» справа вверху):

- фигуры: прямоугольник, квадрат, круг, эллипс, треугольник, линия, стрелка;
- сетевые: ПК, ноутбук, сервер, принтер, IP-телефон, маршрутизатор,
  коммутатор, межсетевой экран (кирпичная стена), точка доступа (дуги),
  облако (контур).

Техника рисования: устройства рисуются «как в легенде» — например,
маршрутизатор = круг + две изогнутые стрелки внутри (3 штриха). После каждого
штриха появляется предложение замены с уверенностью; можно принять топ,
выбрать другой кандидат из списка или оставить исходные штрихи (они сохраняются
в объекте и возвращаются кнопкой «Вернуть набросок»).

Автотест распознавателя (генерирует росчерки с шумом/поворотом/масштабом):

```bash
npx tsx --test tests/recognizer.test.ts
```
